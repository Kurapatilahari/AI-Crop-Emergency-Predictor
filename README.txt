AI CROP EMERGENCY PREDICTOR — SIMPLE WORKING DEMO

HOW TO RUN
1. Extract the ZIP file.
2. Open the AI_Crop_Emergency_Predictor folder.
3. Double-click index.html. It runs in a modern browser; no installation or internet is required.

FEATURES
- Responsive field input form for weather, soil and vegetation-health values.
- Rule-based risk estimate: GREEN / AMBER / RED.
- Threat indicators and practical action suggestions.
- Saves prediction history in browser localStorage.
- Outcome feedback for each prediction.
- Dashboard, view previous predictions, export history as CSV, and clear history.

IMPORTANT
This is a functional educational prototype. It does NOT use a trained machine-learning model, live weather API, real sensors, satellite feeds, SMS, or voice messages. The scoring rules are transparent demo heuristics and are not validated agricultural advice. Validate all field decisions with local agricultural experts.
